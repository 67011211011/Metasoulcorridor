วิธีที่ 1 (เร็วสุด): เปิดสิทธิ์ให้ MetaMask ทำงานกับไฟล์ในเครื่อง

  1. เปิดแท็บใหม่ พิมพ์ chrome://extensions (Edge: edge://extensions)
  2. กด Details ที่ MetaMask แล้วเปิดสวิตช์ Allow access to file URLs
  3. กลับมาที่เกมแล้วกด F5 รีเฟรช

วิธีที่ 2: เปิดเกมผ่านเซิร์ฟเวอร์ในเครื่อง

  1. เปิดโฟลเดอร์ที่มี index.html พิมพ์ cmd ที่แถบที่อยู่ แล้วกด Enter
  2. พิมพ์ python -m http.server 8000
  3. เปิดเบราว์เซอร์ไปที่ http://localhost:8000
  1. ตรวจว่าติดตั้งและเปิดใช้งานส่วนขยาย MetaMask แล้ว (metamask.io)
  2. ปลดล็อก MetaMask ด้วยรหัสผ่านของคุณ
  3. ถ้าใช้หลายกระเป๋า ให้ปิดส่วนขยายกระเป๋าอื่นชั่วคราว แล้วรีเฟรชหน้านี้ (F5)
